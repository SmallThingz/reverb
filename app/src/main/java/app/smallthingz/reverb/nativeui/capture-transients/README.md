# Capture transients

Native implementation of the released Capture save-status and four independent sheet branches. Main owns the 18 dp horizontal/142 dp bottom placement; this component owns neither capture operations nor saved-feedback timers. All actions call the retained NativeCaptureUiOwner. The normal/Range branch switch does not retire the status overlay.

The last non-null card remains until slide/fade exit completes. Saving/Saved replace only their conditional RecordingSummaryCard subtree. Ordinary Library rows retain their default glyph/timestamp/group behavior; optional 22 dp circular progress and trailing Cancel reuse the same source summary geometry. The exact Clear action adds a 19 dp Delete icon,7 dp spacer and palette error-container colors to the existing natural-width Button.

Clear progress switches actual determinate/indeterminate View lifetime according to the source nullable fraction. Both use the source 10 dp pre-transform semantics expansion. Existing sheets rebind the current palette in place, then body/actions, without replacing windows. No accepted service work is cancelled by View disposal.

AndroidX animation-derived algorithms remain Apache-2.0; retained source is animation 1.11.2 EnterExitTransition.kt and the existing LibraryTransitionValue low-level Transition sampler. Four focused motion tests are written. They have not been run here. Source review is not render/frame-phase/keyboard/accessibility or native operation proof. Exact deferred renderedStatus scheduling, shared row/indicator rendering, sheet transitions and input still need the parent's finite release/native qualification. No production Activity route has changed.
