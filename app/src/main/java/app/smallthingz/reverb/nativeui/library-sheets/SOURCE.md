## Remaining qualification / exact limits

This bundle has not been compiled or exercised on a device. Actual Info/button/field raster, font scaling/RTL/tiny constraints, touch/keyboard/IME and sheet drag/Back are pending. The extracted native Editor remains a candidate: native text/cursor/selection/handles, accessibility traversal/actions/selection-mode timing are not proven equivalent to BasicTextField. The demonstrated wrong editable/supporting parentage was corrected in source; that does not prove native accessibility event dispatch or all actions. The public API29 cursor drawable retains the source2dp Float stroke, but native Editor positioning/blink is not source proof; API28 has no public cursor/handle setter. No reflection/private API or tolerance masking is introduced. Source no-autofocus additionally requires shared SheetRoot to own initial window focus as AndroidComposeView does; that narrow shared fix is owned by primitives/root. Pressed mouse delivery requires SheetRoot's existing shared opt-in; hover/wheel are separate.

These limits remain explicit dependencies before production cutover. Source unit checks cannot establish native editing parity, and the shared interop bridge does not turn Android Editor behavior into BasicTextField equivalence. No release recordings/backend/storage semantics or production route has changed.

Library now mounts Info/Rename from its original controller presentation. Same-ID metadata/action/active changes bind existing windows; source removal or screen disposal retires references before cleanup. Root cleanup attempts all resources even when one throws. The transparent Scaffold retains its source inert Surface hit shield so blank Library space cannot target a lower Main sibling. In-place theme rebinding updates existing field/paragraph/button/Info surfaces and cursor/ripple colors, preserving draft, selection, accepted operation, scroll and Window identities; the shared dialog API is owned by the shared-sheet lane. NativeVerticalViewport density/physics stays configuration-lifetime as documented; palette rebinding does not replace it.
