# Native Library accessibility source binding

`NativeLibraryAccessibilityBinding(content, windowText, sourceNode, scrollEvents)` uses the existing Main window cursor and scroll-event queue. Call `refresh()` after actual hierarchy reconciliation and `close()` when the Library owner is disposed. No second text cursor, copied semantic tree, independent frame clock or source-node capture runs per animation frame.

The actual row hierarchy distinguishes source combinedClickable, selected-only semantics and transparent noninteractive wrappers. Merged parents retain separate Text children and the source role-only child where required. Transparent wrappers are skipped by paragraph parent resolution; hidden fake role children do not leak through them. Normal and selection toolbars retain independent source description children using their public shared TopBar binding. Real native clipping supplies the source rectangular layer clips and vertical-scroll cross-axis allowance.

`NativeLibraryRecyclerAccessibility` is shared with Settings because both use the same concrete `ReverbLibraryRecyclerView`. It installs/restores only that View's native delegate, exposes ordered present children, and registers with the supplied shared queue. Foundation1.11.2 LazyLayoutSemanticState supplies total item count by1, pseudo-offset `offset + index*500`, and maximum `value+100` only while forward scrolling is possible. Forward/backward actions use viewport height minus actual before/after content padding. Library has no vertical content padding:84dp is a footer item. Settings bottom24dp is content padding. The existing source scroll owner receives page actions through its same mutex, residual-float accumulation, nested chain and inherited frame clock; no stock RecyclerView fling is introduced.

Parent review corrected the action-admission predicate: source `present` governs whether actions exist; `hidden` and visible-to-user remain independent node fields. Settings review corrected page distance before shared reuse. AppTopBar applies the same presence rule to its description and parent hooks.

This checkpoint is source integration. Actual scroll-event batching, TalkBack traversal, keyboard, clipped/hidden state transitions, recycled row actions, editor/IME and rendered pixel/motion equivalence remain native-unqualified. Prior builds/fixtures are not credited to these newer files.
