Its host supplies the existing16dp horizontal inset and may append the output-compression/silence/notification feature rows directly to the same group. No inner rounded outlines, extra group padding, or inter-row gaps. The standalone slice's lower outer corners do not imply a new boundary between choices and feature rows.

Close the component at its logical composition-owner retirement, not merely on temporary window detach.

Popup is deliberately external. SettingsAudioPopupHost receives typed options/selected identity and existing typed selection callback; no dropdown widget/menu design was substituted. Its owner must preserve source expanded-state lifetime, collapse on inactive panel or removed choice, current option updates, shape18dp container/12dp item clips, selection checkmark, dismiss/focus/back behavior, and invoke the current Settings edit callback before dismissal. It binds expanded fields back to this presentation. This slice alone does not implement or qualify a popup.

Native children retain separate Text and arrow contentDescription nodes, with no invented joined string or Button role. Exact source native-node topology, text traversal/character bounds and screen-reader behavior still need the shared page/window text owner and a real node comparison; source presence does not establish accessibility parity.

Bounded self-review checked independent edge rounding, Row weight/intrinsic width rules, bounded child heights, RTL logical placement, draw order, and avoidance of unconditional paired-row layout requests or per-layout temporary child lists.
