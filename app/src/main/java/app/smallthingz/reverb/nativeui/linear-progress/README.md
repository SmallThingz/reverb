# Default native indeterminate linear progress

Consumer: released 0.1.2 CaptureScreen.kt:2138, ClearBufferProgressSheet's progress-null branch. The save-status card uses the existing circular spinner and is unchanged.

ReverbIndeterminateLinearProgressView(context, environment, frames, scope, durationScale) is an ordinary View. It exposes bindEnvironment(next), bindAccessibility(geometry, exposed), semanticsBoundsInView() and motionScaleChanged() for a caller-supplied scale that changes independently of the platform. The owner must mount/remove it with the source conditional branch, not retain a GONE second indicator. The parent supplies finite width and the same existing sheet/window clock and scope. No new renderer, Composition, frame clock, timer, or backend action is introduced.

The source defaults are 240×4 dp, primary active color, secondaryContainer track, round caps, 4 dp gap, and 10 dp expanded vertical semantics. There is no stop dot in this overload. NativeLinearProgressLine is the exact shared drawLinearIndicator specialization, including directed endpoints, RTL, clamped round caps and the narrow-width Butt fallback. determinate-shared-line.patch only delegates the existing determinate private line method to that helper; its gap/end-dot/progress semantics stay unchanged.

NativeIndeterminateLinearMotion reuses public TargetBasedAnimation/infiniteRepeatable/keyframes. The four tracks have one 1750 ms cycle, staggered delays 0/250/650/900 ms and durations 1000/1000/850/850 ms, using CubicBezierEasing(0.3,0,0.8,0.15). A sampled duration-scale change resets all tracks; zero scale uses target values (all1) and suspends. The View samples with withInfiniteAnimationFrameNanos in the supplied frame-clock context, preserving any installed infinite-animation policy. Window lifecycle admission remains the inherited clock's responsibility; clipping and alpha do not restart the animation.

At zero scale a conflated wake channel suspends without polling. API33+ uses the public ValueAnimator duration-scale listener; API28–32 uses a read-only settings observer. Custom non-platform scale owners must call motionScaleChanged. Both registrations are attach-scoped and removed on detach. Actual pre33 notification ordering, frame/draw phase and suspend/resume behavior need native qualification.

Seven focused tests cover stagger/end values, cycle repeat, positive/zero scale changes, track-only initial/disabled states, gap draw order, RTL and cap fallback. They are written but not run. Source math is not pixel or native motion proof. Actual rendered normal/RTL/narrow bounds, light/dark palette, indeterminate semantics/expanded clipping, theme rebind and lifecycle/scale behavior remain unqualified. Integrated into the native candidate after independent source review. Parent owns build/device; production routes are unchanged.
